This plugin links your WordPress WooCommerce shop to the Lyra payment gateway.

== Description ==

The payment plugin has the following features:
* Compatible with WooCommerce v8.0.0 and above.
* Embedded payment form (hosted by Lyra) in the checkout page.
* Payment by credit card and debit card.
* Payment by Apple Pay, GooglePay, PayPal and other payment methods.
* Possibility to customize the payment form.
* Possibility to refund or cancel a transaction directly from the WooCommerce order page.
* Update orders after payment through a silent URL (Instant Payment Notification).
* Multi languages compliance.
* Multi currencies compliance.

== Installation and upgrade ==

1. Upload the zip file of the plugin through WordPress `Plugins > Add New > Upload Plugin` menu.
2. Activate the plugin at the end of the upload process by clicking the `Enable plugin` or 'Upgrade version' button.
3. To configure the plugin, go to the `WooCommerce > Settings` menu in WordPress then choose `Payments` tab.
